# Angelic's Research World

A personal research website for Angelic Charles, Computational Neuroscientist. Built with Astro, with an immersive neural-inspired visual system, editorial research pages, project explainers for technical and non-technical readers, writing, experience, and an interactive lab concept.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deployable to Vercel. Replace the placeholder biography and project details with verified final copy before public launch.
